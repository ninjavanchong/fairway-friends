# Fairway Friends

Golf scoring app for friends' rounds in Malaysia (React/Vite SPA in `src/`, Express API in `backend/`,
OceanBase/MySQL via Substrait). Repo: github.com/ninjavanchong/fairway-friends (master, push directly).

- **Not yet linked/deployed to Substrait** — local review first. When approved: `substrait-link.sh create --name fairway-friends --repo ninjavanchong/fairway-friends`, then `substrait-deploy.sh --env dev --watch` (prod only via promote, with the user's go-ahead).
- Game + money logic is pure and tested: `backend/engine/` (`npm test`). Handicap is simply strokes for the round; no course/slope rating.
- Course seed `backend/seed/courses.json` (West Malaysia, unverified) is regenerated by `scripts/import-courses.mjs`; seeding is INSERT IGNORE by name so in-app edits survive.
- Migrations are additive Flyway files in `backend/resources/db/migration/`.
- Bash heredocs collapse backslashes: write code containing them with Write/Edit.
